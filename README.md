# Heart Disease Prediction using Machine Learning

This project builds a machine learning model to predict the risk of heart disease based on patient medical data.

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* XGBoost
* Streamlit

## Project Workflow

1. Data cleaning and preprocessing
2. Feature engineering
3. Model training using machine learning algorithms
4. Model evaluation using accuracy and other metrics
5. Deployment using Streamlit for interactive predictions

## Result

The model predicts the probability of heart disease with **85%+ accuracy** and allows users to input medical parameters to get predictions.
